# BRD BPX PRO V1.2 - W1 / L2 / SP UI

## 修改
- [新增] WAIT LOAD：W1 呼吸文字與右側呼吸點，三風格均持續運作，48 幀循環。
- [新增] LOADED：L2 左右括號在 8 幀內向文字收束並保持。
- [修改] MAIN / IR TEST 和備援頁可見的 RPM 改成 SP；底層 RPM 運算與 BLE 封包不變。
- [修改] 移除 NEBULA、DIAL、TORQUE 數值下方重複的 SP（MAX 狀態時對應的數字下方標示一併移除）。
- [保留] BLE、OTA、電池流光、充電偵測、TFT 16 MHz / 33 ms 等設定。

## 避免重疊的文字安全區 (160x80)
- NEBULA：狀態 x80..156、y21..32；獨立於左側儀表 x<=73、數值 y>=36 和電池 y<=16。
- DIAL：狀態 x80..158、y65..77；獨立於數值 y30..46，左下角保留唯一主 SP。
- TORQUE：主 SP 位於左側 x3..38、y8..32；右側狀態 x91..159、y47..58；數字下方不再重複 SP，底部指示條 y65..71。
- L2 左右括號離文字最近不小於 5px；繪圖使用 U8g2 compact 文字實際寬度定位。

## 測試範圍
請在燒錄前確認 U8g2_for_Adafruit_GFX / Adafruit_ST7735 編譯成功；主機模擬字體為 stub，正式字形以 TFT 實機為準。
