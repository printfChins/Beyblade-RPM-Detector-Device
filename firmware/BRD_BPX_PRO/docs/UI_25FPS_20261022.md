# BRD BPX PRO V1.2 — 25 FPS UI 動畫修改

## 修改位置

- `BRD_BPX_PRO/brd_config.h`：五個動畫與畫面排程巨集改為 40 ms。
- `BRD_BPX_PRO/brd_ui_motion.cpp`：說明更新為 25 FPS 目標，更新邏輯仍使用 CFG 定義。
- `BRD_BPX_PRO/brd_ui_transition.cpp`：換頁五步動畫採 40 ms／步。
- `BRD_BPX_PRO/tests/test_25fps_schedule.cpp`：檢查 40 ms 節流與警告閃爍保持 500 ms。
- `BRD_BPX_PRO/tests/run_motion_tests.py`：更新測試檔案路徑。

## 保留

- SPI 16 MHz、TFT 輪詢 10 ms、充電動畫相位 240 ms、警告 500 ms。
- 預設 TORQUE（索引 2），另外保留 NEBULA（0）、DIAL（1）。
- W1／L2、單一 SP、DIAL 恢復狀態、TORQUE 移除 LOAD、量測／BLE／OTA 邏輯。

## 注意

25 FPS 是排程目標，不是實際測得的畫面刷新率；實際幀率會受 CPU 繪圖、SPI 傳輸及非 UI 任務影響。非主畫面（OTA、低電警告、充電亮帶）保留其原有時間基準。
