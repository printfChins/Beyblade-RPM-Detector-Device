# BRD BPX PRO V1.2 — TFT 8 MHz / 20 FPS 動畫更新

## 修改來源
- 最新來源：BRD_BPX_PRO_V1.2_Nebula_RGB_BGR_ColorFix.zip
- 保留：NEBULA、DIAL、TORQUE 三種風格、NEBULA 黃圈旋轉/藍圈峰值、MAX 於主畫面、GPIO5 四頁切換、BLE/OTA、低電紅格閃爍及 RGB/BGR 校正。

## 修改項目

| 檔案 | 原本 | 修改後 |
|---|---|---|
| brd_config.h | 4 MHz（交付 ZIP 原始值） | 8 MHz（使用者已完成硬體測試） |
| brd_ui_motion.cpp | 主畫面/曲線 120 ms、歷史 110 ms | 50 ms（20 FPS 目標） |
| brd_tft.cpp | 外層每 60 ms 取樣/呼叫 UI | 正常頁面每 50 ms |
| brd_ui_transition.cpp | 每步 80 ms | 每步 50 ms（5 步約 250 ms） |
| 低電/ADC 異常 | 500 ms 警告幀、300 ms 外層輪詢 | 500 ms 警告幀、100 ms 外層輪詢 |
| IR TEST | 100 ms 上限、資料改變重繪 | 不變 |

## 可調整設定（BRD_BPX_PRO/brd_config.h）
- TFT_SPI_FREQUENCY_HZ：8000000UL
- BRD_UI_MAIN_FRAME_INTERVAL_MS：50U
- BRD_UI_GRAPH_FRAME_INTERVAL_MS：50U
- BRD_UI_HISTORY_FRAME_INTERVAL_MS：50U
- BRD_UI_IR_FRAME_INTERVAL_MS：100U
- BRD_UI_WARNING_FRAME_INTERVAL_MS：500U
- BRD_UI_TRANSITION_STEP_INTERVAL_MS：50U
- BRD_TFT_POLL_INTERVAL_MS：50U
- BRD_TFT_WARNING_POLL_INTERVAL_MS：100U

## 實作位置
- BRD_BPX_PRO/brd_config.h：調整宏定義。
- BRD_BPX_PRO/brd_ui_motion.cpp：interval(Page) 對應不同頁面。
- BRD_BPX_PRO/brd_tft.cpp：解除原本 60 ms 外層顯示節流。
- BRD_BPX_PRO/brd_ui_transition.cpp：移動排程常數改由設定檔提供。
- BRD_BPX_PRO/BRD_BPX_PRO.ino：不需修改。

## 驗證
- 已通過 12 組主機端功能回歸及 8 組 UI 測試。
- 測試包含 RGB565 Dirty Tile、NEBULA 峰值保持/三狀態、低電 500 ms 閃爍、四頁滑動 50 ms 時序。
- 未在 Arduino ESP32 Core 3.3.11 完整編譯及真實 ST7735 實測 20 FPS。
- 20 FPS 是 50 ms 排程目標，不代表實機一定達到 20 FPS；若畫面繪製/SPI/主迴圈耗時超過 50 ms，實際 FPS 將下降。
