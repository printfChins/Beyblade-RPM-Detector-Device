# BRD_BPX V1.2.3 — LOAD / MAX / HOLD 3 秒狀態機修正

## 完整專案位置

`BRD_BPX/BRD_BPX.ino` 是 Arduino 主程式，所有 `.cpp` / `.h` 與主程式同層。此版本以 `BRD_BPX_V1.2.2_HOLD_LOAD_Guard_Fix.zip` 為基礎。

## 需求實作

1. **WAIT LOAD**：等待 GPIO1 的 LOAD 達到設定去抖時間（預設 50 ms），在此之前不計算 SP。
2. **LOADED**：成功裝載之後開始有效 RPM/SP 計算，所有有效整圈週期都更新本次 `MAX`，並向 BBP Session 保存曲線（上限 32 點）。
3. **達結束門檻**：LOAD 模式使用 `current_SP * 100 <= MAX * finish_percent`，例如 MAX=10000、30% 時，3000 便結束；避免整數小數精度問題。AUTO 模式保留原本 `<` 行為，不在此版變更。
4. **HOLD**：發射完成時先停止 RPM 與 LOAD 中斷事件的入列、清除舊佇列，然後進入獨立 `BRD_STATE_HOLD`，凍結 MAX / 曲線；透過 `brd_bbp_capture_finish()` 標記結果，由原 `brd_bbp_update()` 在主迴圈進行歷史封存與 17-byte BBP Notify，不在 ISR 發送。OLED 首次完整顯示 MAX 後 LOAD HOLD 計時 3000 ms（AUTO 保留 V1.2 的 2500 ms）；OLED 長時間失敗則採用完成時刻起 3000 ms 作備援。HOLD 中 LOAD 彈跳、RPM 脈衝不影響數值和計次。
5. **WAIT LOAD → 新 LOADED 才歸零**：HOLD 到期先恢復 `BRD_STATE_WAIT_LOAD`，保留原 MAX。即使 LOAD 腳位一直為 HIGH，也不能立刻重啟；必須在 HOLD 結束後先觀察真實 LOW 連續去抖 50 ms，再觀察 HIGH 連續去抖 50 ms，才呼叫 `reset_measurement(true)` 清除 MAX 並啟動新量測。OLED 的 WAIT LOAD / LOADED READY 文字以狀態機而非 GPIO 即時電位決定。

## BLE 結果傳送時機

- 本次完整結果只有進入 HOLD 後才凍結並提交 Session。`g_session.update()` 仍由主迴圈處理，使用原 `BBP_PUBLISH_MIN_DELAY_US=600000` 及每頁 `10 ms` 傳送，發送 `B0~B7 / 70~73`，並保留 `0x51` / `0x74` 查詢。
- 既有 LOAD 狀態的 `0xA0` 通知維持 V1.2.1 行為，不算本次發射的曲線資料。
- 若手機未連線、取消訂閱、BLE 堆疊反覆拒絕通知，無法保證 3 秒內送完所有頁面；維持既有重試及 APP 之後使用 `0x74` 讀取已發布歷史的能力，避免靜默遺失完整紀錄。無法用主機端單元測試證明實機無線 3 秒內必達。

## 修改檔案

- `BRD_BPX/brd_config.h`：**修改**版號 V1.2.3、新增 LOAD 專用 HOLD 3000 ms（AUTO 原 2500 ms 保留）、LOAD 結束門檻註解。
- `BRD_BPX/brd_measurement.h`：**新增**獨立 `BRD_STATE_HOLD`（原狀態編碼不變）。
- `BRD_BPX/brd_measurement.cpp`：**修改**LOAD 判定等號、先停 ISR 再凍結、HOLD 3 秒後返回 WAIT LOAD、未重新裝載保留 MAX、顯示狀態與 GPIO 分離。
- `BRD_BPX/tests/test_load_hold_v123.cpp`：**新增**真實量測與 BBP Session 整合測試。
- `BRD_BPX/tests/test_runtime.cpp`：**修改**舊版 HOLD 期間允許寫入設定、百分比必須嚴格小於的錯誤測試假設。
- `BRD_BPX/tests/run_host_tests.py`：**修改**掛入新回歸測試。
- `BRD_BPX/CHANGELOG.md`、`BRD_BPX/V1.2.3_LOAD_HOLD_README.md`：**新增文件紀錄**。

**未修改：** `BRD_BPX.ino`、`brd_bbp.cpp/.h`、`brd_bbp_session.cpp/.h`、`brd_bbp_protocol.cpp/.h`、`brd_battery.cpp/.h`、`brd_ota*`、`brd_oled.cpp/.h` 及 `brd_capture*`（若原專案包含），保留 V1.2.1 的 BLE 主動斷線修正與放電/充電補償，沒有新增 FULL 或 30 秒定期電量 Notify。

## 測試與限制

在 `BRD_BPX/` 下執行：`python3 tests/run_host_tests.py`。測試包含 30% 相等門檻、MAX 上升、3 秒 HOLD、HOLD 期間 LOAD/RPM 訊號忽略、GPIO 持續 HIGH、50 ms LOW/HIGH 去抖後下一發、BBP 歷史計次、BLE 6 組重試／連線案例、電池補償、OLED、OTA、30,000 RPM、micros 回繞／FIFO overflow。

所有測試屬 Linux host mock/仿真，不等同 ESP32-C3 Arduino 目標編譯或實機 GPIO / BLE Notify 驗證。本包**不包含舊的 .bin**，燒錄前需重新編譯。
