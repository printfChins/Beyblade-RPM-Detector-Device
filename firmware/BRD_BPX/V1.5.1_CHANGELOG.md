# BRD_BPX V1.5.1 版本修改說明

## 基準

以 `BRD_BPX_FALLING_RAW_20261119.zip` 為原始碼基準，本版不更改量測或 BLE 協定。

## 變更清單

1. `BRD_BPX/brd_oled.cpp`：主頁一般量測時，左側顯示標籤由 `RPM` 改回 `SP`。發射完成維持 `MAX`。轉速數值來源不變。
2. `BRD_BPX/brd_config.h`：`PROJECT_FIRMWARE_VERSION` 改為 `V1.5.1`，同步作用於 OLED 開機 `FW VER V1.5.1` 與 BLE 韌體版本 API。
3. `BRD_BPX/tests/test_ble.cpp`：版本查詢的預期值改為 `V1.5.1`。

## 保持不變

- GPIO3 Falling Edge 中斷；原始週期記錄及 RPM/MAX 即時計算。
- LOAD / AUTO、停止百分比、HOLD 及其他量測狀態機。
- BLE 通訊協定及停止採樣後才整理並傳輸曲線的行為。
- OLED 排版、字型、電池圖示與原有刷新週期。

## 編譯環境

Arduino IDE 以 `BRD_BPX/BRD_BPX.ino` 開啟，ESP32-C3 開發板、Arduino-ESP32 ESP-IDF >= 5.3；其餘依專案原有設定。
