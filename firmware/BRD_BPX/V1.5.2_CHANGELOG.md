## 電量補償

- 預設電池容量 `300mAh`，預設充電電流 `100mA`。
- 使用 `T(1%) = ceil(36000 * 容量(mAh) / 電流(mA))` 毫秒；例如 300/100 為 108,000ms（108 秒）。
- 保留 21 點電壓→百分比曲線、充電時不直接依端電壓跳升、放電下降可即時反應、拔線 3 秒去抖、低電鎖定機制。
- 只在顯示 SOC 低於 ADC 電壓所推估 SOC 時，通過定時門檻才提高 1%；不單獨認定 FULL。
- 設定被 SAVE 並生效後，若電池容量或電流改變，重新從 1% 時間區間起算。
- 輸入的充電電流**不會更改 TP4056 硬體電流**，建議填入實際充電電流而非 IC 額定最大電流。
- 無電流感測器，無法精準計算 CV 階段以及充電效率差異；此演算法仍是時間補償估計。

## OLED 百分比與左撇子

- 主畫面右上角繪製 `0%`～`100%`，保留 20 像素電池圖、充電閃電。
- `IR TEST` 畫面仍顯示原本的 `x.xxV`，避免更動感測器診斷介面。
- SSD1306 指令：原方向 `A0, C0`；左手 180° `A1, C8`。套用成功立即生效，不改 RAM 內圖形座標及資料採樣。
- 設定在安全 NVS 寫入成功後於 OLED 畫面邊界套用，重新啟動時使用保存方向。

## BLE 設定協議（保持 C1 8-byte / C2 20-byte 不變）

| 參數 | ID | 值 | READ GATT UUID |
|---|---|---|---|
| 電池容量 | `05` | 100～5000 mAh（uint24） | `c7570008-9040-4c7b-87b1-086ef858ace7` |
| HOLD 時間 | `06` | 原 1000～10000 ms | `c7570009-9040-4c7b-87b1-086ef858ace7` |
| 充電電流 | `07` | 10～1000 mA（uint24） | `c757000a-9040-4c7b-87b1-086ef858ace7` |
| OLED 方向 | `08` | `0`=正常，`1`=180° | `c757000b-9040-4c7b-87b1-086ef858ace7` |

新 READ characteristic 各回傳 4 bytes，前 2 bytes 為 active uint16 LE，後 2 bytes 為 staged uint16 LE。

**寫入流程**：C1 GET → C1 SET (ID 5/7/8) → C1 SAVE → 接收 C2 SAVED → 讀 characteristic 核對 active。所有 Flash 寫入仍留在主 loop 的安全量測窗口執行。

## NVS v4 格式

- 24 bytes，`BRDC` magic；版本 `4`；前 16 bytes 保持舊欄位位置不變。
- `[16:18]`: 充電電流 uint16 LE；`[18]`: OLED 方向；`[19]`: reserved=0；`[20:24]`: CRC32(前20 bytes)。
- 16-byte v1/v2、20-byte v3 舊格式均可讀取；缺少新欄位時補 `100mA`／`0°`。
- **向下相容只保證新版讀舊資料**；舊韌體不能解析新版 v4，回退前請先備份設定或預期重設。
