## BLE 修正

- [刪減] V1.2 的 32 筆佇列 overflow -> `disconnect()` 路徑。
- [刪減] V1.2 的 1500ms Notify 失敗 -> `disconnect()` 路徑。
- [保留] 真正手機斷線、取消訂閱仍重設待傳送頁面；仍允許原版新連線競爭時拒絕第二連線。
- [保留] 正常 Notify 每 10 ms 發一頁；**只有** BLE stack 拒收才按 100 ms 節流重試。
- [保留] A0 / B0~B7 / 70~73、APP 0x51/0x74、主動 LOAD/結果 Notify、原版 100ms 訂閱穩定時間。沒有定期 30 秒 A0。
- [注意] `notify()` 成功僅表示交給 stack，非 APP 應用層收到 ACK。

## 電池移植的界限

- [新增] 21 點 SOC 0% = **3460mV**、50% = **3721mV**、90% = **4007mV**、100% = **4150mV**。
- [新增] 200mAh 電池、100mA 理想 CC 速率，`72,000ms / 1%`。顯示上升同時受實測電壓曲線的百分比上限限制；不宣稱實際電池可固定 72 秒增加 1%。
- [新增] 充電開始保持已有電量，不因充電端電壓跳升；CHRG_DET 短暫高電位 3 秒內仍維持顯示；真正拔線後依實測電壓允許向下修正。
- [刪減／不移植] `FULL` 狀態、`FULL` 旗標、4.15V/30 秒 FULL 確認、FULL 解鎖、FULL 亮／滅燈判斷、99% 上限，以及 V1.4 的 3.46V/3.42V **電壓式**低電鎖定。
- [保留] V1.2 的百分比低電保護：開機 `<=8%`、運行中 `<5%`、回復依原 10% / 3 秒規則。**因放電曲線已改，等效觸發電壓會跟 V1.2 不同。**
- [保留] 原 ADC oneshot 校正、每秒一筆、470k/470k 分壓及低電關閉功能。沒有額外 ADC 濾波。
- [注意] 開機已在充電且沒有上次顯示基準時，只能以首次 ADC 電壓建立 SOC；不使用 FULL 判斷就無法區分真正充滿與充電端電壓暫升。
- [保留] V1.2 OLED 電池／閃電的 CHRG_DET 行為；這版**沒有**加入 4.20V 強制熄滅閃電，也沒有改顯示文字 RPM → SP。
