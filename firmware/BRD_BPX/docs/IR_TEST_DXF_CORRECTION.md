# IR TEST：DXF 右側輪廓變形修正（V1.2）

## 修改依據

- 輸入文件：`docs/IR_shape_reference.dxf`，兩組封閉 `LWPOLYLINE`，各六個頂點。
- 修改檔案：`BRD_BPX/brd_oled.cpp`。
- 測試檔案：`tests/render_boot.cpp`、`tests/test_ir_dxf_geometry.py`。
- 本次只改 IR TEST 多邊形繪製和擺位；BLE 設定、量測、OTA、電池 ADC 不改。

## 原因與修正

- 舊版座標已轉向左 90 度，但 `oled_draw_ir_polygon()` **對所有圖形強制左右鏡射**。
- DXF 右側梯形左轉 90 度後，**只具有上下鏡射對稱性**；強制左右鏡射會把較短的左側垂直邊錯誤延長，造成輪廓變形。
- [刪減] 全圖通用左右鏡射補點。
- [新增] 依個別圖形指定正確對稱軸：IR2 左圖上下與左右對稱；IR1 右圖只上下對稱。
- [修改] 從 DXF 頂點直接以統一 `3.5 px / DXF 單位` 縮放並左轉 90 度，避免縮放破壞長寬比。

### OLED 實際座標（128×32）

| 圖形 | 來源 | 實際像素範圍 | 中心 | 對稱性 |
|---|---|---|---|---|
| IR2 左圖 | 六邊形 / GPIO1 | x=38..54、y=12..26（17×15 含端點） | (46,19) | 上下、左右 |
| IR1 右圖 | 六頂點梯形 / GPIO3 | x=73..86、y=8..30（14×23 含端點） | (79.5,19) | 上下（**不**左右） |

旋轉轉換使用相同 DXF 單位比例，`new_x = (max_y - y) * 3.5`、`new_y = (max_x - x) * 3.5`，再四捨五入為像素。兩者水平方向與照片孔洞的左轉 90 度一致。

## 功能保留

- 第一行左 `IR TEST`、右 `BAT x.xxxV`，不繪製原本電池圖示。
- 不顯示 IR1/IR2 文字。
- 未觸發：空心；觸發：實心。
- 右下 BLE 連線或 BLE OFF 提示；OTA 優先顯示邏輯保留。

## 驗證

在 `BRD_BPX` 專案目錄執行 `python3 tests/run_host_tests.py`：

1. 編譯並執行既有八類 host 測試。
2. 以實際 `brd_oled.cpp` framebuffer 產生 IR1 / IR2 / 同時觸發 / 均未觸發四張圖。
3. 檢查右側梯形的「左短、右長」上下鏡射形狀，且不再被強制左右鏡射。
4. `test_ir_dxf_geometry.py` 直接解析 DXF 原始六頂點，對照程式中的旋轉座標。

**注意：** 此結果屬主機端測試，尚未做 ESP32-C3 的 Arduino IDE 實際編譯與 OLED 實機驗證。因未重新編譯實機韌體，不附加新的 .bin，請從本版源碼編譯後再燒錄。
